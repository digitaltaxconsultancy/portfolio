# React eStore – MERN Stack E-Commerce Project

A responsive **eCommerce web application built with React.js**, developed as a hands-on project to practice modern React concepts and frontend development.

The project is being developed as part of a MERN Stack eStore project and covers React fundamentals, component-based architecture, SCSS, responsive design, Redux Toolkit, REST APIs, Node.js, Express.js, MySQL, React Router, and authentication.

## 🚀 Project Overview

This eStore application demonstrates how to build an eCommerce website from the frontend UI through backend API integration.

The project includes:

* Responsive eCommerce layout
* Header and navigation components
* Search functionality UI
* Category navigation
* Side navigation
* Collapsible accordion categories
* Product cards
* Product ratings
* Responsive product layout
* Redux Toolkit for state management
* REST API integration
* Node.js and Express.js backend
* MySQL database
* Product and category management
* Shopping cart functionality
* Product filtering
* Price filtering
* Product details page
* React Router SPA navigation
* Google OAuth authentication

## 🔗 Backend & API

The backend is designed using **Node.js and Express.js** with REST API endpoints.

The application connects to a **MySQL database** to retrieve and manage:

* Categories
* Parent categories
* Products
* Cart-related data

The frontend communicates with the backend using HTTP requests and renders the retrieved data dynamically.

## 🗄️ Database

MySQL is used as the database for storing application data.

The project covers:

* MySQL configuration
* Database creation
* SQL queries
* Connection pooling using `createPool()`
* Fetching category data
* Fetching product data
* API-based database access

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/digitaltaxconsultancy/portfolio/react_estore
```

Navigate to the project:

```bash
cd react_estore
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

For Vite-based projects:

```bash
npm run dev
```
